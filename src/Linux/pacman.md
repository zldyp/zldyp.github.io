# 包管理工具 pacman 命令详解

常用 `pacman` 命令，按使用场景分类整理：

### 一、基础：查看所有已安装包
#### 1. 列出所有已安装包（含版本号）
最常用的命令，输出所有通过 `pacman` 安装的包（包括系统预装和手动安装的），格式为 `包名 版本号`：

```shell
pacman -Q
```

* **参数说明**：`-Q`（Query 的缩写）是 `pacman` 查询已安装包的核心参数，后续所有查询命令均基于 `-Q` 扩展。

#### 2. 列出所有已安装包（带详细描述）
在包名和版本号基础上，额外显示每个包的 **简短描述**（方便快速了解包的用途）：

```shell
pacman -Qs
```

* **参数说明**：`-s`（Search 的缩写）此处用于 “搜索并显示描述”，无额外搜索关键词时，默认显示所有已安装包的描述。

### 二、进阶：按条件筛选已安装包
#### 1. 搜索特定已安装包（按包名匹配）
当知道包名的部分关键词时，用关键词筛选已安装包（支持模糊匹配）：

```shell
# 格式：pacman -Qs 关键词

pacman -Qs firefox  # 查找所有包名/描述含 "firefox" 的已安装包

pacman -Qs "python" # 查找含 "python" 的已安装包（引号可选，含空格时必须加）
```

* **示例输出**：会显示包名、版本、描述，例如 `local/firefox 125.0.3-1 (firefox) Web browser`。
#### 2. 查看 “显式安装” 的包（排除依赖）
系统中很多包是作为 “依赖” 自动安装的（如安装 `firefox` 时自动安装的库文件），此命令仅列出 **用户手动执行&#x20;**`pacman -S`**&#x20;安装的包**（不含依赖）：

```shell
pacman -Qe
```

* **参数说明**：`-e`（Explicit 的缩写），即 “显式安装”。
* **用途**：清理无用包时，可先通过此命令查看自己主动安装的包，避免误删依赖。

#### 3. 查看 “依赖包”（仅自动安装的包）

与 `-Qe` 相反，仅列出 **作为依赖自动安装**、且当前无其他包依赖它的 “孤立包”（可安全清理）：

```shell
pacman -Qtd
```
* **参数说明**：`-t`（Orphan 的缩写，“孤立”），`-d`（Dependency 的缩写，“依赖”）。
* **用途**：定期执行 `pacman -Rns $(pacman -Qtdq)` 可清理无用依赖包（后续会提到）。

#### 4. 查看已安装包的文件列表
想知道某个已安装包在系统中安装了哪些文件（如可执行程序、配置文件、库文件的路径），用以下命令：
```shell
# 格式：pacman -Ql 包名
pacman -Ql firefox  # 查看 firefox 安装的所有文件路径
pacman -Ql python | grep bin  # 筛选 python 安装在 /bin 或 /usr/bin 下的可执行文件
```

* **参数说明**：`-l`（List 的缩写），即 “列出包的文件”。
* **示例输出**：会显示每个文件的绝对路径，如 `/usr/bin/firefox`、`/usr/share/icons/firefox.png`。

#### 5. 查看哪个包安装了某个文件
反向查询：已知系统中某个文件的路径，想知道它属于哪个已安装包（排查文件归属时常用）：
```shell
# 格式：pacman -Qo 文件路径
pacman -Qo /usr/bin/firefox  # 查看 /usr/bin/firefox 属于哪个包
pacman -Qo \~/.bashrc         # 注意：用户目录下的文件（如 .bashrc）通常不属于任何包，会提示“无匹配”
```
* **参数说明**：`-o`（Own 的缩写），即 “查询文件的所有者（包）”。
* **注意**：仅支持系统目录下的文件（如 `/usr/`、`/bin/`），用户自定义文件（`~/.xxx`）无归属包。


#### 6. 查看已安装包的详细信息
查看某个已安装包的 **完整元信息**，包括：版本、发布日期、安装时间、大小、依赖包、维护者、仓库来源等：
```shell
# 格式：pacman -Qi 包名
pacman -Qi firefox
```

* **参数说明**：`-i`（Info 的缩写），即 “显示详细信息”。
* **关键信息**：
  * `Install Date`：安装时间
  * `Size`：包占用磁盘大小
  * `Depends On`：该包依赖的其他包
  * `Required By`：依赖该包的其他包（若为空，说明是孤立包）

### 三、特殊场景：查看包的依赖关系
#### 1. 查看某个包的 “依赖链”（依赖的依赖）
显示某个已安装包的 **所有直接依赖和间接依赖**（递归列出）：
```shell
# 格式：pacman -Qdd 包名
pacman -Qdd firefox
```
* **参数说明**：`-d` 重复两次，即 “显示所有依赖（含间接依赖）”。

#### 2. 查看哪些包依赖某个已安装包
显示所有 **依赖当前包** 的已安装包（即 “被哪些包依赖”）：
```shell
# 格式：pacman -Qet 包名
pacman -Qet python  # 查看所有依赖 python 的已安装包
```
* **用途**：删除某个包前，用此命令确认是否有其他包依赖它，避免破坏系统。

### 四、辅助：输出格式优化（便于后续处理）
#### 1. 仅输出已安装包的 “包名”（无版本号）
当需要用脚本处理已安装包（如批量导出包名）时，仅输出纯包名（无多余信息）：
```shell
# 所有已安装包的包名
pacman -Qq
# 显式安装包的包名
pacman -Qeq
# 孤立依赖包的包名
pacman -Qtq
```

* **参数说明**：`-q`（Quiet 的缩写），即 “静默模式”，仅输出包名，不显示版本号。
* **示例用途**：导出显式安装包列表到文件（用于系统迁移）：

```shell
pacman -Qeq > my\_packages.txt  # 后续可通过 pacman -S - < my\_packages.txt 批量安装
```

### 五、常用命令速查表

| 命令                  | 功能描述                 | 适用场景          |
| ------------------- | -------------------- | ------------- |
| `pacman -Q`         | 列出所有已安装包（包名 + 版本）    | 快速确认包是否安装     |
| `pacman -Qs 关键词`    | 搜索含关键词的已安装包（带描述）     | 查找特定包         |
| `pacman -Qe`        | 列出用户显式安装的包（不含依赖）     | 清理无用包、系统迁移导出  |
| `pacman -Qtd`       | 列出孤立依赖包（可安全删除）       | 清理无用依赖        |
| `pacman -Ql 包名`     | 查看包安装的所有文件路径         | 查找程序 / 配置文件位置 |
| `pacman -Qo 文件路径`   | 查看文件所属的已安装包          | 排查文件归属        |
| `pacman -Qi 包名`     | 查看包的详细信息（依赖、大小、安装时间） | 了解包的完整属性      |
| `pacman -Qeq > 文件名` | 导出显式安装包列表到文件         | 系统迁移、备份安装列表   |

### 补充：查看未通过 pacman 安装的包

如果某个包是通过 **源码编译**、`yay`（AUR 工具）或其他非 `pacman` 方式安装的，`pacman -Q` 无法识别，需用对应工具查看：


* AUR 包（`yay` 安装）：`yay -Qs 关键词`
* 源码安装包：通常无统一工具，需查看安装目录（如 `/usr/local/`）或手动记录。

通过以上命令，可全面管理和查询 Arch 系系统中已安装的包，满足日常使用和系统维护需求。
